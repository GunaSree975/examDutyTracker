# Exam Duty Tracker

A faculty-focused full-stack application for tracking exam duty schedules, parsing uploaded PDF/Excel exam schedules, and storing/retrieving duty assignments through MongoDB.

## Key Features

- Upload and parse `PDF`, `XLSX`, and `XLS` schedule files
- Manual text paste parsing for schedules that do not follow strict formats
- MongoDB-backed duty storage with unique duty normalization
- Faculty dashboard with signup/login via Firebase Authentication
- Search and view duty schedules for faculty names
- Toggle duty completion status from the dashboard
- Static frontend served from `public/`
